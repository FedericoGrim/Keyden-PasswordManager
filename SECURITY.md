# Security Policy

Keyden handles secrets, so please report vulnerabilities privately.

**Do not open a public issue.** Use GitHub's
[private vulnerability reporting](https://github.com/FedericoGrim/Keyden-PasswordManager/security/advisories/new)
(Security tab → Report a vulnerability).

Please include affected component, steps to reproduce, and impact. You'll get an acknowledgement as soon as possible, and credit in the fix unless you prefer otherwise.

Only the latest `main` is supported.
